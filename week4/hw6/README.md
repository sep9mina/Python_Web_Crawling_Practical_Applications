## HTTP 靜態網頁請求（requests）
### 利用 requests.get() 向目標網站發送 HTTP 請求，獲取伺服器回傳的 HTML 原始碼。

## CSS 選擇器定位節點（BeautifulSoup.select()） 
### 使用 BeautifulSoup 解析 HTML DOM 結構。
### 透過 CSS 選擇器階層語法（如 h3 > a）精準批次選取目標元素，而非傳統逐層遍歷。

## DOM 文字提取 vs. 標籤屬性提取（Text vs. Attribute）
### 節點文字（.text / .get_text()）：獲取標籤內包覆的純文字（此處受前端排版限制而被截斷縮寫）。
### 屬性資料（.get('title') / ['title']）：從 HTML 標籤屬性中提取完整原始資料，突破畫面上視覺截斷的限制。

## 資料切片與格式化輸出（Python 基礎語法）
### 使用 Python 串列切片語法（[:5]）限制處理前 5 筆資料。
### 運用 f-string（字串格式化）將畫面上顯示的文字與完整屬性值對照輸出。
